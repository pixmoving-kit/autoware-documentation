# AWSIM 仿真器

[AWSIM](https://github.com/autowarefoundation/AWSIM) 是用于 Autoware 开发与测试的仿真器，最初由 TIER IV 开发，目前仍在积极维护。

开始使用 AWSIM 时，请按照 TIER IV 提供的[说明](https://autowarefoundation.github.io/AWSIM/GettingStarted/QuickStartDemo/)操作。

!!! tip

    AWSIM 有两个版本：

    - 🐇 URP（通用渲染管线）版本： ⭐ **AWSIM-Demo-Lightweight.zip**
      - 推荐使用此版本。
    - 🐢 HDRP（高清渲染管线）版本： **AWSIM-Demo.zip**
      - 此版本的图像效果更逼真，但资源开销很大。

    更多详情见 [AWSIM/Downloads](https://autowarefoundation.github.io/AWSIM/Downloads/)。

!!! warning

    如果您在寻找 [AWSIM Labs](https://github.com/autowarefoundation/AWSIM-Labs)，该项目已归档，请参阅[公告](https://github.com/orgs/autowarefoundation/discussions/6706)。
