# PanoSim 仿真器演示

<a id="overview"></a>

## 概述

PanoSim 是面向自动驾驶及相关技术与产品开发的集成测试仿真平台。

[PanoSim 与 Autoware 联合仿真教程](https://gitee.com/wobuzhuchele/panosim-autoware/blob/master/README.en.md)。
该教程基于 PanoSim V32 和 Autoware Universe，包含桥接、地图、场景和安装说明。
