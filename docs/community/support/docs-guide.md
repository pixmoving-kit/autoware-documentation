# 文档指南

本页介绍几个有助于 Autoware 和 ROS 开发的文档网站。

- [Autoware 基金会](https://www.autoware.org/)是 Autoware 基金会的官方网站，您可以在此了解 Autoware 社区。
- [Autoware 文档](https://autowarefoundation.github.io/autoware-documentation)（本站）是由 Autoware 社区维护的主要文档网站，汇集 Autoware 软件相关的通用信息。
- [Autoware Universe 文档](https://autowarefoundation.github.io/autoware_universe)包含软件组件的 README 和设计文档。
- [ROS 文档指南](https://docs.ros.org/en/rolling/Docs-Guide.html)介绍 ROS 1 和 ROS 2 的文档体系。
